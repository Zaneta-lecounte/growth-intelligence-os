# Qualified Demand Leakage Auditor

## Purpose
Find where qualified demand is being lost between acquisition and revenue.

## Inputs
- leads by source / segment
- MQL, SQL, opportunity, win counts
- acceptance / rejection reasons
- CAC / CPL / cost per SQL / cost per opportunity
- conversion velocity
- sales follow-up timing
- routing performance
- self-service vs enterprise mix
- form / qualification behavior
- source / campaign metadata

## Method

### 1. Build the stage map
Recommended:
Visit → Lead → MQL → SQL → Opportunity → Win

Add company-specific stages where needed.

### 2. Calculate stage conversion
For each source / segment:
- Lead→MQL
- MQL→SQL
- SQL→Opp
- Opp→Win
- Lead→Win

### 3. Find leakage
Flag:
- high-volume / low-quality sources
- sources with strong top-funnel CVR but weak downstream conversion
- routing or SLA losses
- self-service contamination
- qualification mismatches
- source-specific handoff problems

### 4. Quantify opportunity
Estimate the value of improving the weakest high-volume stage.

### 5. Determine likely owner
Classify the problem as:
- acquisition
- web / conversion
- qualification
- operations / routing
- sales handoff
- product / offering
- measurement
