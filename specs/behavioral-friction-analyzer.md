# Behavioral Friction Analyzer

## Purpose
Identify where observed digital behavior suggests confusion, hesitation, abandonment, or unnecessary effort.

## Inputs
- page / screen
- traffic source
- device
- event data
- click data
- scroll depth
- form interaction
- pathing
- session recordings or summarized observations
- page speed / performance
- segment data

## Friction taxonomy
Classify observed friction as:
- comprehension friction
- motivation friction
- trust friction
- effort friction
- navigation friction
- technical friction
- expectation mismatch
- decision overload
- handoff friction

## Method

### 1. Identify anomalous behavior
Look for:
- unusually high exit
- repeated clicks
- low CTA engagement
- form start without completion
- backtracking
- repeated page revisits
- stalled sessions
- mobile/desktop divergence
- source-specific divergence

### 2. Avoid false causality
Behavior alone does not explain why.

For every behavioral signal, state:
- what happened
- plausible explanations
- what customer evidence would strengthen the diagnosis

### 3. Estimate funnel consequence
Connect the friction to:
- conversion stage
- affected volume
- downstream value
- affected segment

### 4. Recommend action
Choose:
- qualitative research
- UX experiment
- messaging experiment
- technical fix
- instrumentation improvement
