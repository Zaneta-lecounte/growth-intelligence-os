# Downstream Impact Analyzer

## Purpose
Evaluate whether an optimization improved business quality, not merely top-of-funnel conversion.

## Inputs
- experiment / intervention
- primary conversion metric
- MQL / SQL / opportunity / win outcomes
- revenue / pipeline
- CAC / source economics
- conversion velocity
- segment / source
- observation window

## Method

### 1. Separate immediate and downstream outcomes
Immediate:
- CTR
- form start
- form completion
- signup
- booking

Downstream:
- qualified conversion
- opportunity creation
- win
- revenue
- CAC
- velocity

### 2. Check for quality tradeoffs
Examples:
- leads up, SQL rate down
- signup up, activation flat
- CVR up, revenue unchanged
- meeting bookings up, attendance down

### 3. Segment the result
Check:
- source
- audience
- device
- intent level
- customer type
- experiment variant

### 4. Determine business interpretation
Classify:
- clear positive
- top-funnel positive / downstream neutral
- volume-quality tradeoff
- inconclusive
- negative
- needs longer observation
