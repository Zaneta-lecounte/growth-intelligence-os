# Hypothesis Evidence Validator

## Purpose
Prevent weak or assumption-led experiments from entering the roadmap.

## Input
A proposed hypothesis plus supporting evidence.

## Hypothesis standard
A strong hypothesis contains:
- observed problem
- affected audience
- proposed causal explanation
- proposed intervention
- expected behavioral change
- expected business outcome

## Validation dimensions

Score 0–2:

### Evidence diversity
0 = one unsupported assumption  
1 = one credible signal  
2 = multiple independent signal types

### Behavioral support
0 = none  
1 = indirect  
2 = direct

### Customer support
0 = none  
1 = anecdotal  
2 = recurring / well-supported

### Business relevance
0 = weak  
1 = moderate  
2 = directly tied to target outcome

### Testability
0 = vague  
1 = partially measurable  
2 = clear causal test

### Measurement readiness
0 = cannot measure  
1 = partial  
2 = reliable

## Total score
0–4: do not test yet  
5–8: research / instrumentation first  
9–12: test-ready
